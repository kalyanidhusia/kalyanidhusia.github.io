Transcription · DNA → mRNA

You are RNA polymerase — read the DNA, write the message.

Genes are instructions stored in DNA, written in four bases: A, T, G, C. To use a gene, the enzyme RNA polymerase slides along the DNA template and builds a matching strand letter by letter, using the pairing rules A–T (2 hydrogen bonds) and G–C (3). RNA has one twist: uracil (U) takes thymine's place, so A pairs with U. The strand you build is mRNA — the message the ribosome will read next.

After playing you can…
  • Pair any base correctly and say how many hydrogen bonds hold it (A–T/U: 2, G–C: 3).
  • Explain what changes in RNA: uracil replaces thymine, so A pairs with U.
  • Describe RNA polymerase's job and what the finished mRNA is for.
