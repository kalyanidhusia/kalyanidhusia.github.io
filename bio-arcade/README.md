# Bio Arcade

Six short browser games, each teaching one biomedical concept to undergraduate students — built under **Arkansas INBRE** (AR INBRE) as part of its student training and AI-in-biomedicine curriculum.

**Live hub:** `https://<your-username>.github.io/bio-arcade/` (GitHub Pages, see Deploy below)

| # | Module | Game | Concept taught |
|---|--------|------|----------------|
| 1 | Central Dogma I | Polymerase Runner | Transcription: base pairing by H-bonds, T→U at the transcription zone, RNA polymerase |
| 2 | Central Dogma II | Ribosome Snake | Translation: codons, AUG start, UAA/UAG/UGA stops, release factors |
| 3 | Protein Folding | Fold-Tris | Hydrophobic effect, misfolding/aggregation, chaperones |
| 4 | Immunology | Phagocyte Patrol | Phagocytosis, opsonization, innate–adaptive teamwork |
| 5 | Pharmacology | Drug Flight | Pharmacokinetics: therapeutic window, clearance, dose timing |
| 6 | Microbiology | Lysis Lab | Peptidoglycan wall, β-lactams, selective toxicity, β-lactamase vs clavulanate |

Every module follows the same evidence-oriented loop — **flashcard (learn) → game (the mechanic is the concept) → 6-question quiz (pass at 5) → named simplifications** — documented in [`docs/PEDAGOGY.md`](docs/PEDAGOGY.md). That loop, not the games themselves, is the reusable contribution.

## Design principles

- **Single-file modules.** Each game is one self-contained `index.html`: no build step, no dependencies, no network calls, works offline once loaded.
- **Mobile-first.** All readable text lives in the HTML DOM (never scaled canvas); canvases render at devicePixelRatio; touch, swipe, and keyboard all work. Students play these on phones.
- **Zero PII.** Nothing is collected. Quiz results produce a verifiable score code students can report; a future opt-in telemetry layer is specified (but not enabled) in [`docs/TELEMETRY.md`](docs/TELEMETRY.md).
- **Scientific honesty.** Every module names its simplifications on the win screen and in its footer.
- **Swappable theme.** Every file starts with a commented `THEME` token block; restyling the whole arcade is a token swap.

## Deploy (GitHub Pages)

1. Push this repository to GitHub.
2. Settings → Pages → Source: *Deploy from a branch*, branch `main`, folder `/ (root)`.
3. The hub appears at `https://<username>.github.io/bio-arcade/`; each game at `.../bio-arcade/games/<slug>/`.

The `.nojekyll` file is intentional (skips Jekyll processing).

## Transferring to an organization

This repo is structured to be transferred intact to an institutional GitHub organization (e.g., an AR INBRE org): Settings → Danger Zone → *Transfer ownership*. GitHub preserves history and redirects old URLs. After transfer, re-enable Pages in the new org and update the hub footer link.

## Maintenance

Modules 1 and 3–6 are generated by [`tools/build_games.py`](tools/build_games.py) (shared CSS/quiz/flashcard framework + per-game data and logic). Edit the generator and re-run it rather than hand-editing those five files. Module 2 (Ribosome Snake) is maintained directly.

Fold-Tris board height is viewport-fitted and tunable without editing code: URL params `?rows=12&cell=36&reserve=220`, or `FTfit({rows:12, cell:36, reserve:220})` in the browser console.
